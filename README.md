# ALMES37 — пирамида Хеопса в 3D

Учебный сайт для портфолио: пирамида в пустыне, артефакты с HUD-разметкой, каменные врата и фигуры из частиц. Всё рисуется в браузере на Three.js, звук синтезируется через Web Audio — без картинок и аудиофайлов.

Идея, структура и эффекты взяты с сайта [Igloo Inc.](https://www.igloo.inc/). Это некоммерческая работа, сделанная только для портфолио.

## Что внутри

- Заставка: каркас пирамиды в сетке линий превращается в камень, проявляется пустыня.
- Пирамида разбирается вокруг курсора, песок продавливается и сам заглаживается.
- Артефакты можно крутить мышкой, у каждого — подписи и «живые» числа.
- Врата из квадратных каменных рамок.
- Фигуры из частиц (сфинкс, искра, уточка) в невидимом стекле, которое вспыхивает от ударов.
- У каждого слайда и перехода свой звук, текст «печатается» при наведении.

## Как запустить

Нужен любой локальный сервер, например Python:

```bash
python -m http.server 5174
```

Затем открыть `http://localhost:5174`.

## Технологии

HTML, CSS, JavaScript (ES-модули), [Three.js](https://threejs.org/) 0.160 с CDN, GLSL-шейдеры, Web Audio API.
